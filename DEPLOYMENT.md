# Развёртывание (Deployment)

## 📦 Особенности деплоя htmlpreview

### Общее описание

Приложение развёртывается через **htmlpreview.github.io** — сервис, который рендерит HTML файлы прямо из GitHub репозитория без необходимости в отдельном сервере хостинга.

### ✅ Что работает

- ✅ Загрузка HTML файла из GitHub (raw.githubusercontent.com)
- ✅ Загрузка CSS через абсолютные URLs
- ✅ Загрузка JavaScript через абсолютные URLs
- ✅ Все операции с локальным состоянием (создание, редактирование, удаление элементов)
- ✅ localStorage для сохранения данных между сеансами
- ✅ Жесты на мобильных устройствах (сенсорные события)

### ⚠️ Ограничения htmlpreview

1. **Относительные пути не работают**
   - ❌ `<link rel="stylesheet" href="list-manager.css">`
   - ✅ `<link rel="stylesheet" href="https://raw.githubusercontent.com/021-lab/searchmydata/branch/list-manager.css">`

2. **CORS ограничения**
   - Запросы к внешним API могут быть заблокированы
   - Для обхода нужно использовать CORS прокси или сервис с CORS headers

3. **localStorage работает в контексте htmlpreview**
   - Данные сохраняются в браузере пользователя
   - Синхронизация с бэкендом требует явной реализации через API

4. **Нет доступа к файловой системе**
   - Невозможно прямо читать/писать файлы (кроме как через API)
   - localStorage - основное хранилище

5. **Сеансы не сохраняются между перезагрузками браузера**
   - Данные только в localStorage (браузер пользователя)
   - Для синхронизации между устройствами нужен бэкенд

### 🔗 Формат ссылки htmlpreview

```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/{OWNER}/{REPO}/{BRANCH}/{FILE}?v={VERSION}
```

**Пример:**
```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/021-lab/searchmydata/claude/repo-access-status-a865fx/list-manager.html?v=7189d3c
```

**Параметры:**
- `?v={VERSION}` — кэширование: изменяет версию при обновлении (commit hash)
- Без этого браузер кэширует старую версию

### 📋 Контрольный список перед деплоем

- [ ] Все относительные пути заменены на абсолютные URLs
- [ ] list-manager.html загружается корректно
- [ ] list-manager.css загружается и применяется
- [ ] list-data.js загружается и инициализирует данные
- [ ] Нет ошибок в консоли браузера
- [ ] Базовая функциональность работает (создание/редактирование элементов)
- [ ] localStorage сохраняет данные между refresh

### 🚀 Процесс развёртывания

1. Разработка на локальной ветке
2. Коммит и push на GitHub
3. htmlpreview автоматически показывает последнюю версию с файла GitHub
4. CI workflow проверяет деплой (см. `.github/workflows/deploy-test.yml`)
5. Если тесты пройдены — деплой готов

### 🔄 Fallback стратегия (будущее)

После реализации Storage Manager:
- localStorage (быстро, на устройстве пользователя)
- Fallback на `list-data.json` (если нет интернета)
- Синхронизация с бэкендом (когда интернет есть)

### 📊 Мониторинг

CI workflow проверяет:
1. Загрузка HTML файла (HTTP 200)
2. Загрузка CSS файла (HTTP 200)
3. Загрузка JS файла (HTTP 200)
4. Рендер через htmlpreview работает
5. Базовые операции DOM доступны
