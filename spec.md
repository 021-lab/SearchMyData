# Список задач — структура данных и интерфейс

**Интерфейс:** [list-manager.html](https://htmlpreview.github.io/?https://raw.githubusercontent.com/021-lab/searchmydata/claude/nested-list-structure-8hrDx/list-manager.html?v=470ff61)

---

## Структура данных

### Схема элемента

```ts
interface Item {
  id:        number;    // уникальный целочисленный идентификатор
  line1:     string;    // название (обязательное)
  line2?:    string;    // подпись
  tags?:     string[];  // теги из фиксированного набора
  collapsed?: boolean;  // свёрнут ли узел (актуально только при наличии children)
  children?: Item[];    // дочерние элементы
}
```

Документ — это корневой массив `Item[]`.

### Пример документа

```json
[
  { "id": 1, "line1": "Молоко 3.2%", "line2": "2 пакета" },
  {
    "id": 2, "line1": "Хлеб ржаной",
    "children": [
      { "id": 26, "line1": "Бородинский", "line2": "400 г" },
      { "id": 27, "line1": "Столичный",   "line2": "500 г" }
    ]
  },
  {
    "id": 3, "line1": "Яблоки", "collapsed": true,
    "children": [
      { "id": 28, "line1": "Голден",      "line2": "500 г", "tags": ["Купить"] },
      { "id": 29, "line1": "Гренни Смит", "line2": "400 г" }
    ]
  },
  { "id": 4, "line1": "Кофе", "line2": "Арабика, зерно, 250 г", "tags": ["Важное", "Срочно"] }
]
```

### Набор тегов

Фиксированный набор (изменяется только в коде):

| Тег | Тег | Тег |
|-----|-----|-----|
| `Важное` | `Срочно` | `Купить` |
| `Дом` | `Работа` | `Отложить` |

### Нотация путей JSON Patch (RFC 6902)

| Путь | Что адресует |
|------|-------------|
| `/0` | первый элемент корневого массива |
| `/2` | третий элемент корневого массива |
| `/-` | позиция после последнего элемента массива (только для `add`) |
| `/1/children/0` | первый дочерний элемент второго корневого элемента |
| `/1/children/-` | добавить в конец массива `children` |

## Действия

### 1. Добавить элемент в корень

**Как:** кнопка `+` → заполнить модальное окно → «Добавить»

Элемент добавляется в конец корневого массива.

```json
[
  {
    "op": "add",
    "path": "/-",
    "value": { "id": 32, "line1": "Название", "line2": "Подпись" }
  }
]
```

---

### 2. Добавить вложенный элемент

**Как:** свайп вправо → «Вложенный» → заполнить модальное окно → «Добавить»

Элемент добавляется как последний дочерний у выбранного родителя.

Если `children` уже существует:
```json
[
  {
    "op": "add",
    "path": "/1/children/-",
    "value": { "id": 32, "line1": "Дочерний элемент" }
  }
]
```

Если `children` ещё нет:
```json
[
  {
    "op": "add",
    "path": "/1/children",
    "value": [{ "id": 32, "line1": "Дочерний элемент" }]
  }
]
```

---

### 3. Редактировать элемент

**Как:** свайп вправо → «Изменить» → изменить поля → «Сохранить»

```json
[
  { "op": "replace", "path": "/0/line1", "value": "Новое название" },
  { "op": "replace", "path": "/0/line2", "value": "Новая подпись" }
]
```

---

### 4. Просмотреть элемент

**Как:** свайп вправо → «Просмотр»

Открывает модальное окно только для чтения. Документ не изменяется.

```json
[]
```

---

### 5. Удалить элемент

**Как:** свайп вправо → «Удалить»

Удаляет элемент вместе со всем поддеревом.

```json
[
  { "op": "remove", "path": "/2" }
]
```

---

### 6. Управление тегами

**Как:** свайп влево → панель тегов → выбрать тег

Повторный выбор уже назначенного тега снимает его.

**Добавить тег** (массив `tags` существует):
```json
[
  { "op": "add", "path": "/0/tags/-", "value": "Срочно" }
]
```

**Добавить первый тег** (массива `tags` ещё нет):
```json
[
  { "op": "add", "path": "/0/tags", "value": ["Срочно"] }
]
```

**Снять тег** (по индексу в массиве):
```json
[
  { "op": "remove", "path": "/0/tags/0" }
]
```

---

### 7. Свернуть / развернуть узел

**Как:** касание / клик по элементу, у которого есть дочерние элементы

`collapsed: true` — дочерние элементы скрыты в интерфейсе, но присутствуют в документе.

**Свернуть:**
```json
[
  { "op": "replace", "path": "/1/collapsed", "value": true }
]
```

**Развернуть:**
```json
[
  { "op": "replace", "path": "/1/collapsed", "value": false }
]
```

---

### 8. Перетащить элемент (изменить порядок)

**Как:** удерживать элемент ≥ 370 мс → перемещать вертикально → отпустить

Элемент перемещается вместе со всеми дочерними элементами. Относительный порядок детей сохраняется.

```json
[
  { "op": "move", "from": "/3", "path": "/1" }
]
```

---

### 9. Углубить уровень вложенности при перетаскивании

**Как:** во время вертикального перетаскивания сместить вправо ≥ 36 пикселей

Элемент получает уровень вложенности на единицу больше, чем у соседнего элемента сверху.
Дельта уровня применяется ко всем дочерним элементам пропорционально.

Эффект эквивалентен:
```json
[
  { "op": "remove", "path": "/3" },
  {
    "op": "add",
    "path": "/2/children/-",
    "value": { "id": 5, "line1": "..." }
  }
]
```

---

### 10. Отменить последнее перетаскивание

**Как:** кнопка `↩` в заголовке

Восстанавливает снимок документа, сделанный непосредственно перед drag-операцией.
Доступна сразу после завершения перетаскивания. Глубина отмены — 1 операция.

```json
[
  { "op": "replace", "path": "", "value": "<снимок документа>" }
]
```

---

### 11. Голосовой ввод (PTT)

**Как:** удерживать кнопку `🎤` → говорить → отпустить

Записывает аудио и отправляет на сервер. Изменений в документе не производит.

```json
[]
```

## Инварианты документа

| Правило | Описание |
|---------|----------|
| `id` уникален | Значение `id` уникально во всём дереве, включая вложенные уровни |
| `line1` непустой | Элемент не может быть создан или сохранён с пустым `line1` |
| Теги из набора | Каждый тег в `tags[]` принадлежит фиксированному набору (см. выше) |
| `collapsed` без детей | Поле `collapsed` имеет смысл только если `children.length > 0` |
| Одна отмена | Undo хранит один снимок; доступен только сразу после drag |
